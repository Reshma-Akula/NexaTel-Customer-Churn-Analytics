# NexaTel Customer Churn Analytics

## Project Overview

NexaTel Customer Churn Analytics is an end-to-end data analytics project focused on understanding customer churn, retention, revenue risk, customer segments, service quality, and campaign performance.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Excel

## Project Phases

### Phase 1 — Data Cleaning
- Cleaned customer and subscription data
- Handled duplicates and invalid records
- Validated billing data
- Created analysis-ready datasets

### Phase 2 — Exploratory Data Analysis
- Analyzed customer churn
- Studied tenure and customer segments
- Examined billing and subscription patterns
- Identified churn trends

### Phase 3 — KPI & Cohort Analysis
- Calculated churn and retention KPIs
- Analyzed recurring revenue and MRR
- Estimated revenue lost to churn
- Calculated customer lifetime value
- Performed cohort retention analysis

### Phase 4 — Power BI Dashboard
Created a 5-page management dashboard covering:

1. Executive Overview
2. Customer & Segment Analysis
3. Service & Support
4. Network & Regional Analysis
5. Campaigns & Revenue

**Dataset:** The analysis was performed using NexaTel customer, subscription, billing, support, network, and campaign datasets. The raw and cleaned datasets are not included in this public repository. 

## Key Business Insights

- Overall churn rate: 18.45%
- Customer retention: 81.55%
- 3,506 customers churned
- Monthly revenue at risk: approximately ₹2.57M
- MRR: approximately ₹14.92M
- FCR: 40.41%
- Average resolution time: 15.96 hours
